# Trusted visual rendering contract

ChatGPT selects approved data after inspecting the generated photographs. Pillow validates and draws the exact source. No visual child ever writes drawing code or changes copy.

## Allowed data

Each card has `confidence`, `design` (`hybrid` / `editorial`), an approved `palette` ID, `category_style`, `heading_tone`, `photo_window` and ordered `blocks`. Older local plans may omit the new fields and receive trusted defaults. Palette IDs come only from `data/design-palettes.json`. A photo window is null or `{y, height, fit}`: x64/width952 are fixed, y250–770, height400–800 (240–800 for visual-identification quizzes), fit `contain` for hybrid or `cover` for editorial. Full-background hybrid uses the feed crop. A contained photo remains complete; an editorial cover crop requires a visual assessment that required subjects survive.

Each block allows only `role`, `style`, `x`, `y`, `width`, `font_size`, `line_spacing`, optional `max_lines` (null or1–12) and `wrapping` (`balanced` or `natural`). Answers additionally allow `marker_style`: circle, rounded_square, square or triangle. Body/example roles cannot supply this field. All text comes from the exact reviewed card; there is no text field in the proposal. Blocks preserve source order and every role. Examples additionally allow `photo_tone` from the photographic colour enum. Bodies/answers cannot supply it. Bodies/answers additionally choose `panel_opacity`: a numeric percentage from 70 through 100 inclusive (fractional percentages allowed). Plain editorial body accepts only 100 because it has no panel; examples cannot supply panel opacity. Labels/title typography and anchors stay renderer-controlled.

Natural wrapping is greedy; balanced wrapping distributes the minimum number of lines without tiny orphan lines. Unicode spaces preserve exact reconstruction; NBSP, narrow NBSP and word joiners remain unbreakable. Diacritics and combining characters are never stripped or normalised for drawing.

No proposal may supply drawing primitives, replacement text, code, CSS, font paths, custom hex colours, fade alpha, panel opacity outside 70–100%, borders/radii/shadows or arbitrary filter definitions.

Stories keep treatment B and select the matching feed card's final approved palette. Final safe data is captured in the private placement result and GitHub report; no raw model prose is logged.
