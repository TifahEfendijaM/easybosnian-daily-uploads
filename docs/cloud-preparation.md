# Cloud preparation

The user requested moving preparation to the cloud on 2026-10-02. `.github/workflows/preparation.yml` runs at 20:00 Europe/Sarajevo; `daily.yml` is called automatically after successful preparation and a three-minute delay. There is no separate publisher cron. Pause the local Codex heartbeat after the cloud connection check passes. No awake computer or open desktop app is required afterward. No scheduled retry exists.

Use a **separate cloud-only ChatGPT login**, never a copy of the desktop session. `scripts/cloud_auth_setup.py login` opens official browser sign-in with an isolated ignored credential directory. Complete sign-in yourself. `scripts/cloud_auth_setup.py save` stores managed authentication only in this exact private repository's `CODEX_AUTH_JSON` secret. Do not copy tokens into chat, commits or artifacts, or subsequently execute that credential on this Mac or another runner.

The official CLI is pinned to `@openai/codex@0.160.0`. The workflow is serialized, restores the current secret into its private temporary directory, runs Codex normally, and saves the **updated** file back to GitHub secrets in an always-run step. The existing repository-restricted `GH_SECRETS_TOKEN` grants write-back. API-key and external-token authentication are refused. The research child receives no Instagram, Cloudflare administrative or GitHub credential. Credentials and raw agent events are excluded from artifacts and summaries. Revoked authentication or subscription usage limits stop preparation with an actionable private failure; there is no paid fallback.

Manual dispatch is **connection verification only**. It checks Instagram infrastructure without publishing, reads all private history and queue packages, makes one minimal ChatGPT call, then writes/reads a non-content proof at `docs/cloud-preparation-proof.json`. It neither chooses/reserves content nor enables Cloudflare publishing. A successful run also confirms credential write-back. Set `CLOUD_PREPARATION_ENABLED=true` after this succeeds. Arm `DAILY_POSTING_ENABLED=true` for the authorized scheduled pipeline; Cloudflare's separate `daily_enabled` gate remains false until an actual reviewed package is reserved, saved and read back.

At the scheduled time, the wrapper resumes any same-date reservation. Otherwise the research agent reads the full prompt and durable instructions, private history and every queue package, performs source/semantic review, writes a draft and measures text fit. The wrapper independently validates, reserves, saves and reads back, then enables Cloudflare publication under the user's existing authorization. The separate publisher handles images and Instagram. A connection or code check never proves publication.

Research is limited to seven minutes; workflow startup and cron can still be delayed. Late/incomplete batches report failure and are preserved without a retry or manual publication dispatch. Failure issues and the 21:59 monitoring-only Worker remain active; Healthchecks email setup is deferred. Private GitHub runners consume included Actions minutes; keep paid spending disabled. ChatGPT usage consumes the existing subscription's limits.
