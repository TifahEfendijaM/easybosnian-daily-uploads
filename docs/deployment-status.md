# Deployment status

The daily clock remains 05:00 Europe/Sarajevo, cron `0 3,4 * * *`, gated by scheduledTime for DST. Multiple-batch support uses the same Worker/D1/KV and migration 0005; the morning dispatch creates an independent current-date batch with mode=daily and batch_target=none. Manual latest replacements keep their selected batch’s date/ID. A commit alone never deploys Cloudflare. Live migration/bundle/clock and publication-kill-switch restoration evidence is recorded in the task’s release output after actual deployment. No live test, catch-up, retry or cron-claim reset is introduced.
