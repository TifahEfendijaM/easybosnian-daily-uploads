# Free service boundaries

Use the existing Workers Free account, D1 and KV only. No paid model/API, R2, paid Buffer plan, auto-upgrade or paid failure fallback.

A normal day needs three Free FLUX.1 Schnell backgrounds, four steps each, then local Pillow rendering. Previews and same-day replacements may use additional Free quota; replacement invalidates only that batch’s caches. Cached backgrounds are reused by a subsequent preview of the same batch. Stop and report provider quota failures instead of switching services.

KV stores generated/private/card/Story images for 14 days, with random public URLs for final images only. History and cron claims do not expire automatically. GitHub artifacts retain safe results/cards for seven days. GitHub private runners and ChatGPT preparation use the account's included allowance; subscription/runner limits can block a run and are not a reason to buy or silently use an API.

Fresh public image visibility uses bounded read-only GET polling on explicit 404 responses, up to 180 seconds per image at five-second intervals. It verifies exact bytes before a provider receives the URL. Public exposure uses the submitted renderer bytes, avoiding an immediate private-KV read. KV image reads use cacheTtl=30, the documented minimum; this reduces negative-cache lifetime but does not make KV strongly consistent. No write, generation or publication is repeated. Nine image exposures at most cover the three feed cards and three Stories per enabled Meta platform.

Buffer remains on Free with one TikTok channel and one three-image feed post per routine day. Its conservative documented budget is 3,000 requests/month and ten queued posts per channel. Read-only polling is capped at 13 checks over four minutes for one accepted submission. No scheduled repost/retry exists. Instagram, Facebook and Stories similarly poll only their current containers/returned posts. Facebook publishes three fresh unpublished photo uploads as correctly sized A/B image Stories; it does not generate extra FLUX backgrounds. Story read-back is capped at six read-only polls, up to five cursor pages per poll, for each accepted photo. There is no second publication attempt. Manually starting daily again can submit additional posts, as the user explicitly accepted.
