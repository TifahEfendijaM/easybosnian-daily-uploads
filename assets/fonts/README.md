Bundled fonts for reproducible cloud rendering

Inter files retain their existing LICENSE.txt. Lora.ttf and Lora-Italic.ttf are unmodified variable fonts from the official Google Fonts distribution, licensed under the accompanying Lora-LICENSE.txt (SIL OFL 1.1). Lora uses weight600 for headings and400 for true italic examples. Both include Bosnian Latin characters. No macOS/Georgia system font is copied or required.
